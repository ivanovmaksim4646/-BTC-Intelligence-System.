# Dual chart dashboard
Open index.html via a static web server (e.g. python -m http.server from repository root, then /charts/). GitHub Pages deployment is not enabled by this PR. Official TradingView widget is for viewing only; it is not scraped. Independent Lightweight Charts uses existing public OKX closed OHLC snapshots and same-source swing context. D1 has FVG only unless aligned context exists. BTC.D/TOTAL/TOTAL2/TOTAL3 use original widget only, no invented independent OHLC. FVG boundaries are historical observations, not active POIs. OB, BOS/CHOCH, Sweep and report image delivery are not implemented. No trading logic, secrets or schedules changed.
